# Диско-год

Командная викторина-вечеринка в стиле диско-телешоу 80–90-х: угадайте, когда вышла песня или случилось событие, и поставьте карточку в свою ленту годов.

## Как играть

1. Откройте `index.html` на ноутбуке, подключённом к телевизору.
2. Ведущий сканирует маленький QR «Пульт ведущего», команды сканируют большой QR.
3. Ведущий нажимает «Начать игру» на телефоне.

Режим «Одно устройство» (кнопка вверху лобби) работает без телефонов.

## Устройство кода

- `js/config.js` — все числа правил.
- `js/bank.js` — банк карточек.
- `js/engine.js` — логика игры: состояние меняется только через `reduce(state, action)`.
- `js/net.js` — связь телевизора с телефонами (PeerJS / WebRTC). `?net=local` — проверка во вкладках одного браузера.
- `js/app.js` — экраны телевизора, `js/phone.js` — телефоны ведущего и команд.

Сборка не нужна: это статический сайт.
